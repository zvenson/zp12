Rescue a stuck FM-1

for developers

No installer finds the FM-1 any more, or an update stopped and it will not come back? Its chip has a bootloader in ROM that no firmware can overwrite. Two steps put any firmware from this hub back on through it. Linux for now.

The screen stops and the computer sees a USB disk "UBOOT1.00". Nothing is written yet: switching the FM-1 off and on brings it back as it was.

curl -fsSLO https://thefirmwarehub.com/rescue/fm1_rescue.py
sudo python3 fm1_rescue.py sloop

It checks before it writes: the chip, the flash, the chip key, the package. It writes only the firmware area, never the bootloader, reads every sector back and restarts the FM-1. --check only looks. fm1_rescue.py (GPL-3.0), the bootloader protocol after jl-uboot-tool (MIT), whose flash helper for the chip it downloads.

On Windows, or with a full backup first: MvaveFM1Unbricker by Quixotic7 (MIT) takes the same way in. It reads the whole flash twice and keeps it, writes only the firmware area and checks every byte. An FM-1 that never shows "UBOOT1.00" at all comes back with its Transporter guide and a small RP2040 board.

Which custom firmwares are there for the M-VAVE FM-1?

All free and open source (GPL-3.0): Felucca, the custom firmware the others build on, and Felucca [Salt], its fork with a browser Studio; SLOOP, a live groovebox, and sloopDX, SLOOP with a DX7 inside; zp12, a standalone 12-bit sampler and drum machine; X0X, 909/808 drums and two 303s; FoMni, a chord harp; ChoralRoot, a chord instrument; Jangada, dark drones and ten engines; Melodee, microtonal scales, a CZ-1 and a Dexed; Hortator, an eight-track drum machine; FiMba-1, a kalimba; GHOULBOX, dungeon synth with a cathedral reverb and a hurdy-gurdy; SLOOP Floyd FM, a visual four-operator FM engine; SLOOP DX7 Banks, twelve DX7 banks in SLOOP; WaveLoop, Felucca played from an Arturia MiniLab 3; JIANT FM, six tracks as living beings in thermal colours; fm1-chord, a chord machine after the HiChord; FuMi-1, a shigin conductor after the Suiko ST-50; MAKU, an ambience machine for DJ interludes; Rainbow Mode, a music toy for little children; AMB-1, a generative ambient machine after Music for Airports; CTL-1, a MIDI controller with sounds of its own; Polly, a pocket arranger whose band follows your chords; winampFM Synth, Winamp 2.x with your sounds as a playlist; MYCELIUM, Forest, Psytrance and Goa grooves; Bubba Machine, a six-track groovebox written from scratch; ETCH, waveforms you draw and morph; FM-106, a Juno-106; TRIBE, ten tracks where any engine plays anywhere; DUELL, a bitimbral morphing synth; Skiff, six tracks and fourteen engines; ORBIT, a four-track groovebox with OP-1-style screens; Felucca 8 Patterns, eight sequences a track; and Fart Machine One, which is exactly what it says. Make firmware, not war: you do not have to choose one for good.

How do I install a firmware on the FM-1?

In Chrome or Edge (they speak Web MIDI): connect the FM-1 by USB, press Connect the FM-1, then Install on the firmware you want. About a minute, the FM-1 restarts as a different instrument. No app, no driver, no file to download.

Why only open-source firmwares?

The hub lists firmwares that are free software, released with their source (GPL-3.0): so every package can be mirrored unchanged, checked and kept available, and anyone can see what it does. Closed or paid firmwares are not listed.

Why is Baud Girl only a link? Where is Groove OS?

Both are fine firmwares for the FM-1, but neither is open source: there is no published source and no license that allows passing the package on, so this page may not mirror them. Baud Girl is asked for so often that it has a card anyway: the button takes you to Madeline's own installer (free, tips on Ko-fi). Groove OS installs from groove-os.com. If either becomes open source with a release on GitHub, it goes on here like the others.

Is it always the newest version?

Yes. Every night the hub looks at each project's repository and offers its newest release, after checking that the package is an FM-1 firmware with the update loader. Betas are marked.

How do I go back to the official firmware?

Download FM-1 V15 from m-vave.com and install it with the box above. If the FM-1 is stuck, hold OCT− while switching it on (USB rescue) and install again; if no installer finds it at all, rescue it with a hub firmware first.

My FM-1 is stuck: no installer finds it any more. Is it bricked?

Almost certainly not. The FM-1's chip has a bootloader in ROM that no firmware can overwrite. The Rescue box sends the FM-1 there and gives you two commands for a Linux terminal that put any firmware from this hub back on: they check the chip and the package first, write only the firmware area and read every sector back.

What happens when you press Install

The page talks to the FM-1 over USB MIDI with the same update protocol as M-VAVE's own updater (first the running firmware stages the new package's update loader, then the loader writes the firmware). The package is checked first (its SHA-256 against the catalogue). Nothing goes to a server: the packages come from this page, mirrored unchanged from each project's GitHub release.
