Questions

Which custom firmwares are there for the M-VAVE FM-1?

All free and open source (GPL-3.0): Felucca, the custom firmware the others build on, and Felucca [Salt], its fork with a browser Studio; SLOOP, a live groovebox, and sloopDX, SLOOP with a DX7 inside; zp12, a standalone 12-bit sampler and drum machine; X0X, 909/808 drums and two 303s; FoMni, a chord harp; ChoralRoot, a chord instrument; Jangada, dark drones and ten engines; Melodee, microtonal scales, a CZ-1 and a Dexed; Hortator, an eight-track drum machine; FiMba-1, a kalimba; GHOULBOX, dungeon synth with a cathedral reverb and a hurdy-gurdy; Bubba, an eight-track groovebox with a sampler and a looper on every track; SLOOP Floyd FM, a visual four-operator FM engine; SLOOP DX7 Banks, twelve DX7 banks in SLOOP; WaveLoop, Felucca played from an Arturia MiniLab 3. Make firmware, not war: you do not have to choose one for good.

How do I install a firmware on the FM-1?

In Chrome or Edge (they speak Web MIDI): connect the FM-1 by USB, press Connect the FM-1, then Install on the firmware you want. About a minute, the FM-1 restarts as a different instrument. No app, no driver, no file to download.

Why only open-source firmwares?

The hub lists firmwares that are free software, released with their source (GPL-3.0): so every package can be mirrored unchanged, checked and kept available, and anyone can see what it does. Closed or paid firmwares are not listed.

Where is Baud Girl? Where is Groove OS?

Both are fine firmwares for the FM-1, but neither is open source: there is no published source and no license that allows passing the package on, so this page may not mirror them, and it only lists firmware it can take unchanged from a public release. Install them from their makers: Baud Girl (free, tips on Ko-fi) and Groove OS. If either becomes open source with a release on GitHub, it goes on here the next day.

Is it always the newest version?

Yes. Every night the hub looks at each project's repository and offers its newest release, after checking that the package is an FM-1 firmware with the update loader. Betas are marked.

How do I go back to the official firmware?

Download FM-1 V15 from m-vave.com and install it with the box above. If the FM-1 is stuck, hold OCT− while switching it on (USB rescue) and install again.

What happens when you press Install

The page talks to the FM-1 over USB MIDI with the same update protocol as M-VAVE's own updater (first the running firmware stages the new package's update loader, then the loader writes the firmware). The package is checked first (its SHA-256 against the catalogue). Nothing goes to a server: the packages come from this page, mirrored unchanged from each project's GitHub release.
